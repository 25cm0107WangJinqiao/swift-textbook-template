# ピアレビュー記録：第2回

> レビュー実施日：2026-06-17
> レビュー対象者：卞宜璇
> 対象の章：第2章：地図アプリの基本

## 良かった点

1.コードの役割の解説が分かりやすいです
「なぜこう書くのか」「もしこう書かなかったら」のところが、理由と失敗の例がセットになっていて良かったです。特に Identifiable がないと「背番号がないからエラーになる」という説明は、初心者の私でもイメージがしやすかったです。

2.実験メモが具体的で参考になりました
Marker と Annotation の違いを自分で動かして確認しているのがすごいです。デザインを自由に変えたい時は Annotation を使えばいいという基準がはっきり分かりました。

3.全体のコードが綺麗にまとまっています
iOS 17の新しい Map の書き方が全部入っていて、コピペするだけで動く状態になっているので、教科書として使いやすいと思いました。

## 改善提案

1.模範コードと詳細解説の内容が少しズレている気がします
「📌 このアプリは何をするものか」の文や詳細解説では、手動でデータを定義した Landmark や LandmarkCard について説明していますが、上の模範コード（全体像）は CLLocationManager や MKLocalSearch（APIでの周辺検索）のコードになっています。
もし手動データのフィルタリング（Landmark と Category）を説明したいなら、模範コードもそちらに合わせた方が、読んでいて混乱しないと思います。

2.「4. フィルター機能」のコードが全体像にないです
詳細解説の3番、4番に出てくる selectedLandmarkID や filteredLandmarks のコードが、上のメインビュー（ContentView）の中に書かれていません。解説にあるコードはすべて、上の全体像のコードの中にも入れておいてほしいです。

## 自分の教科書に活かしたいこと

テーブル（表）を使って文法やAPI（Identifiable や MapCameraPosition など）をまとめる書き方がとても見やすかったです。
私の教科書は文章ばかりで読みづらいので、大事なキーワードやクラス名は、卞さんのように表にして整理するエッセンスを取り入れたいと思います。
